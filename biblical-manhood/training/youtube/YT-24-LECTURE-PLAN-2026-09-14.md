## 4. Script template (beat sheet)

Gold master: W1 RUNDOWN + DIALOGUE + `studio/voice/MAX-VOICE-BIBLE.md`. Fable 5.1 fills this skeleton per week.

```markdown
# Steadfast Men — Week N of 24: [TITLE] (LECTURE)

Max solo. Source: FLOW [chapter files]. Runtime ~30 / cap 40. Spoken budget 4200–4800.

## Meta
- Format: Lecture. Single teacher to camera and room.
- Set: Standing, lectern/high stool camera right, book closed until opened on purpose.
- Four marks: 2× verbatim (open + close).
- Closer: Name it / Do this week / Tell a brother / Carry this.
- Original only. No Hawks/Lewis/Ted/Red Rocks reprint. No em dashes.

---

## 1. COLD OPEN [00:00 | ~2–4:30]
- Week's belonging line or locked open (W1: "Sit down. You are on time.").
- How to take the class (one session / do the work / come back; notes by hand).
- Name seats in the room as the week requires (young / single / married / wounded / older / high performer) — plain, not soft-church.
- Four marks #1 + "write it down."
- **No subscribe. No follows. No site. No music.**

## 2. THE CLAIM [after open | ~2–3 min]
- One sentence claim of the chapter/week.
- Define terms. Say what the claim does **not** say.
- Write-down cue.

## 3. THE TEXT [~3–4 min]
- Primary Scripture NIV, cited in the spoken line.
- 2–3 observations. Definition if the book supplies one ("say it with me").
- On-screen verse + citation.

## 4. TEACHING MOVEMENTS [bulk of runtime]
For each movement (usually 3–4):
- Teach the beat.
- Original Max illustration that costs him (tell on himself, then land).
- Mark touch if earned (1–4).
- Summary line a man can write.
- Optional pattern interrupt / hold (silence is a tool).
- Edit holds named in RUNDOWN (do not cut away on cost lines).

## 5. MARKS INTEGRATION
- Touch relevant marks inside movements; full creed again in close.
- Never swap a word of the four marks.

## 6. YOUR TURN / APPLICATION [~2–4 min]
- Guided, undramatic. Worksheet energy (two columns / one blank / hour audit — week-specific).
- Direct address to the seat this week most tempts to leave.
- Aligns with packet closer later (but do not read the packet on mic).

## 7. CLOSE [~2–3 min]
1. **Name it.** One sentence, out loud, tonight.
2. **Do this week.** One concrete practice.
3. **Tell a brother.** Text template optional.
4. **Carry this.** One locked line for the week.
5. Four marks #2.
6. Dismissal / sign-off (week-specific).

## 8. SUBSCRIBE CTA (spoken default)
- Last ~15–20s only (optional one mid-ask after real payoff ~12–16 min):
  - Subscribe + bell to stay with the 24 sessions / next week's table.
  - Name **next session title** for end-screen bridge.
- Do not pitch shop, Stripe, apps, smash-that-like, follows, or site on mic until Aaron revises SHOW-BIBLE.

## 9. DESCRIPTION + PINNED (always in rundown notes)
- End card: next session + Subscribe.
- Description 150+ words: synopsis, chapters/timestamps, Session N of 24, playlist link (when live).
- Pinned + description footer: CROSS-LINKS YouTube skip-self block (see §2).
- Support/access: description only until Aaron unlocks spoken.

## 10. END CARD [last 15–20s]
- Visual: next week title + Subscribe.
- Verbal CTA lands **when** end screen appears, not after.
```
