## 4. Top YouTube lecture / training series patterns (research)

Patterns below are **structural ideas only**. Do not plagiarize titles, hooks, scripts, or branding from any channel. Steadfast remains original FLOW teaching.

### 4.1 Sources consulted (cite, do not copy)

- PreVideo — "Structuring YouTube videos for conversion — the 2026 guide" (https://prevideo.io/en/blog/youtube-videos-strukturieren-2026) — HIVE model, retention benchmarks, CTA timing.
- LensPOV — "How to Script YouTube Videos for High Retention (2026)" (https://lenspov.com/articles/how-to-script-youtube-videos) — hook / segment / next-video bridge.
- TubeVertex — hook–body–CTA retention notes (https://tubevertex.com/youtube-scriptwriting-the-hook-body-and-cta-formula-that-holds-80-watch-time-in-2026/).
- Impact+ — YouTube marketing 2026: benefit-led subscribe, playlists (https://www.impactplus.com/learn/youtube-marketing).
- VID — educational hook types and mid-video CTA placement (https://vid.co/video/how-to-write-a-video-script-for-youtube).
- All-in-1 Panel — educational series length / AVD / returning viewers (https://allin1panel.com/my-best-educational-series/).
- YTShark — series planning, open loops, end screens (https://ytshark.com/how-to-plan-youtube-video-series/).
- Alan Spicer — binge playlists, numbered episodes, weekly cadence (https://alanspicer.com/youtube-series-strategy-create-binge-worthy-content-playlists/).
- Ali Abdaal materials — HIVE / HIVES, core curriculum architecture, end-screen topical bridge (aliabdaal.com YouTube guides; creator-economy case notes on numbered series).
- Primetime Media — course playlist sequencing and chaptering (https://primetime.media/blog/optimize-your-youtube-course-playlist-a-tactical-playbook-for-engagement-beginner).

### 4.2 Pattern digest (adapt to Steadfast locks)

| Pattern | Industry common practice | Steadfast adaptation |
|---|---|---|
| **Cold open / hook** | 0–15s: result, problem, or contrarian claim. No greeting. No early subscribe. | Max: "Sit down. You are on time." / week's promise. Dry open. No music. No CTA. |
| **Roadmap** | 15–60s: what you'll cover + open loop | Name claim + "three/four movements" + write-down cue |
| **Body** | 2–3 min segments; What–Why–How; pattern interrupts / re-hooks every 60–180s | Numbered movements + illustration + summary line; hold on cost beats |
| **Chapters** | YouTube chapter timestamps in description | Build into every RUNDOWN (TC column already in W1) |
| **Length** | Many edu series 8–15 min; deep lectures longer | **Locked ~30 / max 40** class lecture (not short-form tutorial) |
| **CTA timing** | No CTA first minute; soft mid after value; strong close + end screen | Subscribe+bell; mid after payoff; close with next week; socials in description per CROSS-LINKS |
| **Subscribe language** | Benefit-led ("subscribe for weekly X"), not "smash like" | Mission frame: stay through session 24 / next week's table. Fortune 500. No smash. |
| **Series navigation** | Numbered titles; playlist autoplay; pin playlist; prev/next in description; end screen → next ep | "Session N of 24"; Start Here playlist; cards to playlist; verbal next-week title |
| **Release** | Weekly same day; often launch 2–3 eps then weekly | Recommend: clear W1–W3 scripts before first upload; batch buffer |
| **Retention metrics** | AVD, returning viewers, playlist views-per-start | Track after publish (not now) |
| **Open loop** | Tease next installment at end | Carry line + "Session N+1: [title]" |

### 4.3 "Best of the best" lecture-series traits to emulate (craft only)

1. **Numbered curriculum with a clear finish line** (Ali Abdaal-style architecture: standalone value + progressive incentive to start at ep 1).
2. **Consistent episode shape** so returning viewers know the ritual (Steadfast closer + four marks already do this).
3. **Teacher authority without hustle** (class craft; Fortune 500 bar; kill ministry-YouTube warmth).
4. **Playlist as the product** (one Start Here path: W1→W24).
5. **End-screen bridge** to the *specific* next session, not a random video.
6. **Description does the commerce/navigation** so the spoken hour stays teaching.

## Meta

## 1. COLD OPEN [00:00 | ~2–4:30]

- Name seats in the room as the week requires (young / single / married / wounded / older / high performer) — plain, not soft-church.
- Four marks #1 + "write it down."

## 2. THE CLAIM [after open | ~2–3 min]
- One sentence claim of the chapter/week.
- Define terms. Say what the claim does **not** say.
- Write-down cue.

## 3. THE TEXT [~3–4 min]
- Primary Scripture NIV, cited in the spoken line.
- 2–3 observations. Definition if the book supplies one ("say it with me").
- On-screen verse + citation.

## 4. TEACHING MOVEMENTS [bulk of runtime]
For each movement (usually 3–4):
- Teach the beat.
- Original Max illustration that costs him (tell on himself, then land).
- Mark touch if earned (1–4).
- Summary line a man can write.
- Optional pattern interrupt / hold (silence is a tool).
- Edit holds named in RUNDOWN (do not cut away on cost lines).

## 5. MARKS INTEGRATION
- Touch relevant marks inside movements; full creed again in close.
- Never swap a word of the four marks.

## 6. YOUR TURN / APPLICATION [~2–4 min]
- Guided, undramatic. Worksheet energy (two columns / one blank / hour audit — week-specific).
- Direct address to the seat this week most tempts to leave.
- Aligns with packet closer later (but do not read the packet on mic).

## 7. CLOSE [~2–3 min]
1. **Name it.** One sentence, out loud, tonight.
2. **Do this week.** One concrete practice.
3. **Tell a brother.** Text template optional.
4. **Carry this.** One locked line for the week.
5. Four marks #2.
6. Dismissal / sign-off (week-specific; W1: "Get out of the truck.").
