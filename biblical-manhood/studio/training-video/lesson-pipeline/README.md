# lesson-pipeline: how Steadfast Men lesson videos are made (L02 onward)

- `LESSON-VIDEO-SOP-v2.md`: the process, the rules (every Aaron correction) and the correction log. **Read it first.**
- `new_lesson.sh NN "LNN-Title-Words"`: makes `/home/claude/lNN/` from the template.
- `template/`: the code that built the locked L04 v3 (edit/ = cut, render, QC; plan/ = cues, words, picture maps, audio, captions; gfx/ = board builder, plus L04's boards as an example).
- `graphics/`: the board renderer, HTML templates, Geist fonts and the logo lockup (walksteadfast.com design system).
