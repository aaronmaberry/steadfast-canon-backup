## 7. Tool decision: Resolve MCP vs Descript vs our pipeline
- DaVinci Resolve MCP: samuelgursky/davinci-resolve-mcp (MIT, ~3.7k stars, 37 compound / 390 granular tools, Studio needs External scripting=Local; free edition only via an in-app bridge script) and hiteshK03 (free-edition bridge). Runs on Linux, but this box has no GPU (no nvidia-smi), 15 GB RAM, Debian 13; Resolve needs a supported CUDA/OpenCL/Metal GPU and a desktop session, and has no headless mode. Not runnable here. It would need Aaron's own GPU machine (+$295 Studio for the reliable path). Its value = a real NLE timeline for a human fine-cut, which we don't have.
- Descript (connected): tools = import_media, prompt_project_agent (Agent Underlord edits by natural language: can add captions, layouts, B-roll/stock, zooms, Studio Sound, remove filler), export_timeline (Premiere/Resolve XML/FCPXML/AAF/EDL), export_transcript, publish_project, search_drive, jobs. Uploading our 984 MB master = an upload (needs Aaron's OK); agent edits are not frame-exact and not reproducible.
- Ours (python/OpenCV + ffmpeg, intro render_v3 helpers): frame-exact, free, deterministic, already matches the brand. The gap is the visual vocabulary, not the tool.
Recommendation: stay on our renderer for build; add (1) a paper-edit step, (2) an effects library (below), (3) free stock B-roll (Pexels/Pixabay, licence logged) and HyperFrames-style HTML motion graphics rendered locally, (4) export an FCPXML/Resolve XML of each cut so Aaron could fine-cut in Resolve on his own machine if he wants.
