# Condensed Training

The chapters you just read are the book. What follows is a short map for the **first twenty-four weeks of the class**, not a full index of every chapter.

Each class week walks one chapter, sometimes a tight pair, with a video teaching, a leader guide, and a participant worksheet. The closer stays the same all the way through. Name it. Do this week. Tell a brother. Carry this.

Use this back section as a compact agenda if you are already in a group and need the spine on paper. For the printable packets, host scripts, and the week-by-week run order, including the weeks that cover the rest of this book, get the class guide at walksteadfast.com.
