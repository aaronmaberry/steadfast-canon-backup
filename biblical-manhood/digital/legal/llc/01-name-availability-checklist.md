## What “available” means in Texas (and what it does not)

Texas SOS will not file a Certificate of Formation if the name is **not distinguishable in the records** from existing filing entities, registered foreign entities, fictitious names of registered foreign entities, registered series names, and existing name reservations/registrations (BOC § 5.053; 1 TAC ch. 79, subch. C).

SOS **does not**:

- Search trademarks for you
- Guarantee you can use the name in commerce
- Block assumed names (DBAs) that look similar — Chapter 71 does **not** authorize rejection of an assumed-name certificate for name conflict
- Give you exclusive brand rights by issuing Form 205

## Assumed name / DBA if the storefront is “Steadfast Men”

Legal name on Form 205: **Steadfast Men, LLC** (must include an LLC designator).

If the public storefront, Stripe descriptor, app name, or site header is **Steadfast Men** without “LLC,” Texas treats that as an **assumed name** for a filing entity. After (not before) SOS accepts the LLC:

- File **Form 503** with the Texas Secretary of State (**$25**). LLCs file assumed names **with SOS**, not the county clerk (HB 3609, effective 1 September 2019).
- An assumed name is **notice**, not exclusive rights. SOS will file the same assumed name for multiple people.
- You **cannot** file an assumed name that is the entity’s **exact** legal name (e.g. you cannot DBA “Steadfast Men, LLC”). “Steadfast Men” without the designator is the usual storefront filing.
- Duration: up to **10 years**, then refile.
- **Do not file Form 503 from this pass.** Wait until the LLC exists.

Optional later: also file “The way of Godly Men” as a separate assumed name if that tagline will be used as a business name in commerce (separate $25 certificate). Counsel of record should decide whether the tagline needs its own certificate or is just a slogan.
